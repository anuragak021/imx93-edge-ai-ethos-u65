# Edge AI on the NXP i.MX 93 Ethos-U65 NPU

An int8-quantized MobileNetV2 running on the Ethos-U65 NPU of a FRDM i.MX 93, compiled with Vela, benchmarked
against the Cortex-A55 CPU, with a Python classifier that runs on either. Every number below comes from the
raw logs in `results/`; the table is generated by `tools/make_results.py`.

## Board and software (from `results/board_probe.txt` and `results/board/env.txt`)

- FRDM i.MX 93, NXP prebuilt Linux BSP: NXP i.MX Release Distro 6.6-scarthgap, kernel 6.6.36-lts-next, aarch64
- On-board Vela 3.12.0, `tflite_runtime` 2.16.2, Ethos-U delegate `/usr/lib/libethosu_delegate.so`, device `/dev/ethosu0`
- Laptop: Python 3.10, TensorFlow 2.15.1 (converter only, see `requirements.txt`)

## Results

Latency per inference in ms, MobileNetV2 224x224 int8, batch 1, 200 steady-state runs after 10 warm-up runs.
"Median" and "first run" come from `board/bench.py` (per-run CSV in `results/board/`). The benchmark_model columns are
the TFLite tool's own average and first inference (it does not report a median).

| Config | Median (ms) | First run (ms) | benchmark_model avg (ms) | benchmark_model first (ms) | runs |
|---|---|---|---|---|---|
| CPU 1 thread, XNNPACK (default) | 40.77 | 46.77 | 40.41 | 49.91 | 200 |
| CPU 2 threads, XNNPACK (default) | 22.95 | 28.69 | 22.85 | 28.74 | 200 |
| CPU 1 thread, XNNPACK off | 68.01 | 74.62 | 67.70 | 79.03 | 200 |
| CPU 2 threads, XNNPACK off | 49.10 | 55.52 | 48.99 | 55.34 | 200 |
| NPU (Ethos-U65, Vela model) | 3.48 | 3.70 | 3.48 | 3.58 | 200 |

NPU speedup (ratio of medians): **11.7x** vs CPU 1 thread and **6.6x** vs CPU 2 threads, both with XNNPACK (the
fastest CPU configuration measured); 19.5x and 14.1x vs the same thread counts with XNNPACK off.

| | Size |
|---|---|
| int8 TFLite before Vela | 3,991,688 bytes |
| after Vela (NPU model) | 3,607,424 bytes |

**Operator placement** (`results/vela_summary.txt`): 96 of 96 operators on the NPU, 0 on the CPU, so there was no
operator fallback for this model. Vela's own cycle-model estimate is 4.24 ms; that is an estimate, the measured
number is 3.48 ms. Confirmed at run time: `EthosuDelegate: 1 nodes delegated out of 1 nodes` (`results/board/bm_npu.log`).

**Accuracy (`results/quantize_log.txt`, laptop):** top-1 on 50 held-out Imagenette-val images, scored by 1000-way
argmax against the mapped ImageNet class: float32 0.78, int8 0.72. The set is small, so treat the gap as indicative.

**CPU vs NPU agreement on the board (`results/results.md`):** top-1 identical on 49 of 50 images. The one
difference (`n02979186_40.JPEG`, CPU "cassette player" vs NPU "tape player") is a near-tie: the NPU scores both
classes -41, the CPU scores -40 vs -47 (`results/board/infer_cpu.log`, `infer_npu.log`); the CPU and NPU int8
kernels round slightly differently.

## Method and caveats

- Latency is the `invoke()` call only (image decode and preprocessing excluded), on random int8 input for the benchmark loop
  (latency does not depend on values). Classification latency per image is printed by `infer.py`.
- Warm-up is reported separately: the first inference is slower on every configuration.
- The CPU baseline is the default TFLite build with XNNPACK; XNNPACK-off rows are included for reference only.
- Not recorded: CPU clock and governor (this BSP exposes no cpufreq sysfs), board temperature, power. One board, one run
  of the suite; run-to-run variation was not measured beyond the p95/max in the per-run CSVs.
- `black` reformatted the Python files after the board run; the formatting change is whitespace only.

## Reproduce

Laptop (quantize):
```
uv venv --python 3.10 .venv && uv pip install --python .venv/bin/python -r requirements.txt
# download imagenette2-320 (https://s3.amazonaws.com/fast-ai-imageclas/imagenette2-320.tgz) and extract it
.venv/bin/python model/quantize.py --dataset <path>/imagenette2-320
```
Board (all commands as run; the board is reached over serial `picocom -b 115200 /dev/ttyACM1` and SSH):
```
scp model/mobilenet_v2_int8.tflite board/infer.py board/bench.py board/run_benchmarks.sh root@<board>:imx93/
# copy model/sample_list.txt images to imx93/samples on the board
cd imx93 && vela mobilenet_v2_int8.tflite --accelerator-config ethos-u65-256 --output-dir vela_out | tee vela_summary.txt
sh run_benchmarks.sh results                                   # runs every configuration, saves raw logs
python3 infer.py --device cpu --model mobilenet_v2_int8.tflite --images samples
python3 infer.py --device npu --model vela_out/mobilenet_v2_int8_vela.tflite --images samples
```
Back on the laptop: copy the board `results/` to `results/board/`, then `python3 tools/make_results.py`.

Wi-Fi: the NXP driver was not loaded on this image, so I ran `modprobe moal mod_para=nxp/wifi_mod_para.conf` by hand and
gave connman the network through `/var/lib/connman/*.config`. I did not make the module load persistent or test a reboot.
No credentials are stored in this repo.
